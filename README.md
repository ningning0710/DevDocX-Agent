# DevDocX - 開發者文件與程式碼架構分析 AI Agent

> 智慧化 GitHub 專案導讀與系統架構分析 Agent | 中央大學 AI Agent 課程專案

## 💡 專案簡介

**DevDocX** 是一款專為軟體工程師、系統架構師與技術學習者打造的 **AI 輔助程式碼與文件導讀工具**。本專案旨在解決開發者在閱讀陌生專案或大型開源 Repo 時的邏輯梳理痛點，透過 LLM 自動提取專案關鍵架構、解析 API 規格，並轉化為清晰易懂的系統導覽圖。

---

## 🎯 解決問題與使用場景

### 1. 解決問題
* **新手接手專案門檻高**：面對邏輯龐雜的既有程式碼（Legacy Systems），需耗費大量工時逐檔比對與追蹤變數。
* **技術文件維護欠佳**：專案開發速度快於文件更新，導致團隊常需靠閱讀原始碼來確認實際運作方式。
* **第三方套件上手慢**：官方 SDK 或 API 文件內容瑣碎，難以在短時間內掌握核心調用邏輯與範例。

### 2. 使用場景
* **GitHub 儲存庫自動解析**：輸入 GitHub 專案網址，Agent 自動掃描目錄結構、識別套件依賴，並梳理模組間的調用關係。
* **架構文件深度對話**：上傳系統設計規格書（PDF/Markdown），針對關鍵演算法與邏輯流程進行即時問答與細節追蹤。
* **卡片化與圖表化輸出**：自動將解析成果整理為標準 JSON 格式與 Mermaid 架構視覺化圖表，方便直接同步至團隊知識庫（如 Notion、Confluence）。
